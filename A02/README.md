A02 number 10

This program works by reading a text file and a: counts the number of lines beginning with an uppercase letter and b: counts the number of empty lines, including lines containing only whitespace. The result is printed in the terminal

How to run the script:
Clone the repository from GitHub:
git clone git@github.com:amare2004/ci2.git

Go to the correct directionary
cd ci2/A02

No external Python packages are required in this assignment. So the requirements.txt file is empty.

Run the script:
python3 texter.py test.txt

The test.txt file included in the folder can be used to test the program. If no file name is provided then a instruction message will be printed.
